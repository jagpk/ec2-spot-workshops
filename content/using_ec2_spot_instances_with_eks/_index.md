### Overview

In this workshop, you learn to deploy and scale a stateless application cost effectively using [Amazon Elastic Kubernetes Service (Amazon EKS)](https://aws.amazon.com/eks/) and [Amazon EC2 Spot Instances](https://aws.amazon.com/ec2/spot/).

### Setting
You have been provided with a sample application deployed on EKS managed node groups with On-Demand capacity and a sample tool to simulate load. You are tasked to move the sample application to EKS managed node groups with Spot capacity, scale using Kubernetes Cluster Autoscaler, and test the application for resiliency and scale. 


### Prerequisites
This is **L400** workshop that requires readers of this workshop to have basic knowledge of **Kubernetes**, **Amazon EKS**, and **AWS CloudFormation**. If you are not familiar with these concepts then go through below content before starting the workshop:

:pushpin: [Basics of Kubernetes](https://www.eksworkshop.com/010_introduction/basics/)
