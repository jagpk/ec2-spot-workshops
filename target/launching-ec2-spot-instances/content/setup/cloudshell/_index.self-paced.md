In this workshop you use [AWS CloudShell](https://aws.amazon.com/cloudshell/) to run [AWS Command Line Interface (CLI)](https://aws.amazon.com/cli/) commands. AWS CloudShell is a browser-based shell console that makes it easy to securely manage, explore, and interact with your AWS resources. You can access CloudShell from AWS Web Console, in the same way that you access other AWS services. You will find a shortcut in the top navigation bar, to the right of the search bar (highlighted in green in the image). You can as well type *CloudShell* in the search bar and it will appear in the search results panel.
