### Overview

This AWS CloudShell based lab gives you a walk-through of options to launch EC2 Spot Instances for use-cases, where you require granular controls. You create a launch template, and then use it to launch EC2 Spot Instances using Amazon EC2 Auto Scaling groups, EC2 Fleet, Spot Fleet, and RunInstances. Additionally, lab covers Spot dashboards to visualize savings, pricing and interruptions.

### Intended Audience

DevOps Engineers, Infra Admins, Developers, and Architects

### Pre-Requisites for this lab:

 - A laptop with Wi-Fi running Microsoft Windows, Mac OS X, or Linux.
 - An Internet browser such as Chrome, Firefox, Safari, or Edge.
 - An AWS account with admin access to create AWS resources during the workshop.

The expected duration of this workshop is about 1 hour.
